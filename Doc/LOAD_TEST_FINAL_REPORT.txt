================================================================================
TROUBLESHOOTING
================================================================================

Tests Fail to Start
→ Check services: curl http://localhost:8000/api/health
→ Verify Playwright: npx playwright --version
→ Reinstall: npm install && npx playwright install chromium

High Error Rates
→ Check backend logs: tail -f ../backend/app.log
→ Check database: Review connection pool settings
→ Check Redis: redis-cli ping

Slow Performance
→ Monitor resources: top, free -h
→ Check database: Review slow query log
→ Adjust pool: Edit backend/app.py pool_size

Tests Timeout
→ Increase timeout in playwright.config.load.js
→ Or: npx playwright test --timeout=600000
