## 2. Insiden Kritis Ditemukan & Diatasi

### Production DB Schema Hilang
**Root cause:** File test (`backend/tests/test_*.py`) menggunakan `os.environ.setdefault("DATABASE_URL", "sqlite:///:memory:")`, tapi `.env` sudah meng-export Postgres URL ke shell — `setdefault` jadi no-op. Test kemudian `db.drop_all()` ke production database.

**Fix:**
- DB restore dari `backups/daily/pg-2026-05-22.sql.gz` (13 tabel, 1 user, 2 papers)
- `backend/tests/conftest.py:1` di-harden: **force-override** `DATABASE_URL` ke sqlite + `RuntimeError` guard kalau URL non-sqlite

**Bukti:**
```
Pre-restore log: 33,231 errors (UndefinedTable: slr_jobs/image_gen_jobs)
Post-restore + restart: clean, 0 new errors
```

### Detail per agent

**Agent 1 (Single-shot generator):**
- `_extract` walked dict values tapi tidak cek list items → figures/tables/equations always empty. Rewrote untuk cek `obj.get("id")` lalu recurse dict+list uniformly.
- `_normalize_paper_shape` tidak handle nested `section2a/section3b` keys → tambah `_lift_subsections` + `_SUBSECTION_KEY_RE`.
- References shape `{"title": "REFERENCES", "content": [...]}` salah-extract → kini handle `content` first, fallback skip `title` key.

**Agent 4 (File upload):**
- DISCOVERY_PROMPT rewrite dengan FILE UPLOADS block: `paper_slr`, `paper_read` (skip SLR), `data`, `image`, `template`
- AI wajib panggil `AskQuestions` per file_id, lalu `ClassifyFile` per jawaban
- File >3000 words trigger `ReviewLargeFile` proposal otomatis
- REVISI mode juga dapat 4 tool tambahan: AskQuestions, ProposeChips, ListAttachedFiles, ReadAttachedFile

**Agent 5 (Image worker):**
- Atomic `UPDATE WHERE status='queued'` claim (dulu racy read-then-write di `:97-106`)

- Bounded `_dispatched` set (dulu unbounded leak di `:259-268`)

9. Klik "Jalankan SLR" → progress: Antri → AI ringkas 10/20 → AI ringkas 20/20 ✓
10. **Hasil: 20/20 literatur tampil di tabel** dengan badge "✨ AI summaries enabled" ✓
11. Kirim chat: "Generate paper lengkap... Pakai 20 literatur SLR" ✓
12. AI eksekusi tool chain: `RouteIntent(revisi)` → `GetLiterature(50)` → `GetPaperContent` → `ProposeAbstract` → `ProposeSection ×4` (PENDAHULUAN, TINJAUAN PUSTAKA, METODOLOGI PENELITIAN, HASIL DAN PEMBAHASAN) ✓

### Catatan tentang flow `ProposeSection`
Section card muncul sebagai **proposal** yang butuh klik "Accept" user untuk commit ke `paper.data`. Ini by-design dari perintah `revisi` mode — section per section dengan review user. Untuk single-shot tanpa proposal, AI dapat panggil `GenerateFullPaper` tool yang invoke worker async ke V-OPUS (teruji di unit test, model lock V-OPUS hard-coded di `generate_paper_single.py`).
