🕳️ Gap (Celah Riset)
Kondisi Saat Ini	Masalah
Chatbot kampus kebanyakan masih rule-based atau FAQ statis	Tidak bisa jawab pertanyaan di luar pattern yang ditentukan
LLM standalone (tanpa RAG) sering halusinasi data akademik	Jawaban ngawur & tidak berdasarkan dokumen real
Belum banyak studi RAG domain akademik Bahasa Indonesia	Evaluasi performa RAG di konteks kampus lokal masih minim
✨ Novelty (Kebaruan)
RAG khusus domain akademik Bahasa Indonesia — integrasi dokumen asli kampus (buku pedoman, SK rektor, FAQ prodi)
Eksperimen chunking strategy + embedding model — bandingkan performa (misal: chunk size 500 vs 1000 token)
Evaluasi multi-metrik — tidak cuma accuracy, tapi juga faithfulness, context recall, answer relevancy
🎁 Kontribusi
✅ Chatbot RAG yang bisa menjawab pertanyaan mahasiswa secara akurat dari sumber dokumen resmi
✅ Hasil evaluasi kuantitatif performa RAG di domain akademik lokal
✅ Rekomendasi konfigurasi optimal (chunking, embedding) untuk dokumen akademik

🧪 Langkah 4: Metodologi
Jenis Penelitian: Eksperimental kuantitatif

Tahapan:

Pengumpulan Data — scraping/kumpulkan dokumen akademik kampus (buku pedoman, FAQ, SK rektor, website prodi)
Preprocessing — cleaning teks, chunking dokumen (variasi: 500 vs 1000 token)
Embedding & Indexing — embedding model (text-embedding-3-small vs Ada-002), vector store (ChromaDB)
RAG Pipeline — LangChain + OpenAI GPT-4o-mini, retrieval top-k (3, 5, 7)
Evaluasi — 50 pertanyaan uji, metrik: precision, recall, MRR, faithfulness, answer relevancy
Analisis — bandingkan hasil antar konfigurasi
📄 Langkah 5: Struktur Abstract
Latar belakang → Gap (chatbot rule-based belum adaptif, LLM halusinasi) → Metode (RAG + LangChain + OpenAI) → Hasil (skor akurasi & metrik) → Kesimpulan + implikasi
