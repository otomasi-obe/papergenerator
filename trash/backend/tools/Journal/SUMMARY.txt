2. Template API (template_api.py)
   - GET /api/templates - List all templates with filters
   - GET /api/templates/<code> - Get template details
   - POST /api/templates/<code>/validate - Validate paper against template
   - GET /api/templates/fields - List available fields
   - GET /api/templates/citation-styles - List citation styles
   - GET /api/templates/types - List template types
   - GET /api/templates/search - Search templates
   - POST /api/templates/recommend - Get template recommendations

TEMPLATE METADATA STRUCTURE
---------------------------
Each template includes:
- Code, name, full name
- Template type (Journal/Conference/Thesis/Report)
- Fields (Computer Science, Engineering, etc.)
- Citation style (IEEE, APA, ACM, etc.)
- Publisher, country, language
- Layout (columns, page size)
- Requirements (abstract, keywords, word limits)
- Formatting rules (section numbering, etc.)
- Feature support (equations, figures, tables)

SAMPLE USAGE
------------

Python:
```python
from templates.template_registry import get_template, validate_paper_for_template

# Get template info
template = get_template("IEEE")
print(template.full_name)  # "IEEE Transactions Standard Format"

# Validate paper
errors = validate_paper_for_template(paper_data, "IEEE")
if errors:
    print("Validation errors:", errors)

# List templates by field
from templates.template_registry import list_templates, TemplateField
cs_templates = list_templates(field=TemplateField.COMPUTER_SCIENCE)
```

API:
```bash
# Get all templates
curl http://localhost:5000/api/templates

# Get IEEE template details
curl http://localhost:5000/api/templates/IEEE

# Validate paper
curl -X POST http://localhost:5000/api/templates/IEEE/validate \
  -H "Content-Type: application/json" \
  -d '{"title": "My Paper", "abstract": "...", "keywords": ["AI", "ML"]}'

# Search templates
curl http://localhost:5000/api/templates/search?q=computer

# Get recommendations
curl -X POST http://localhost:5000/api/templates/recommend \
  -H "Content-Type: application/json" \
  -d '{"field": "Computer Science", "type": "Journal Article"}'
```
