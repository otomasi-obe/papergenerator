🖥️ Word Desktop (Windows) Paling umum

Untuk Word terinstall di PC Windows. Add-in dimuat dari folder bersama (shared folder).

  1. Download file manifest.xml (tombol di atas), simpan di sebuah folder, misal C:\WordAddIn.
  2. Bagikan folder itu: klik kanan folder → Properties → tab Sharing → Share… → pilih akun Anda → Share. Catat path UNC yang muncul, contoh: \\NAMA-PC\WordAddIn
  3. Daftarkan katalog di Word: buka Word → File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs
  4. Pada kolom Catalog Url, masukkan path UNC folder (BUKAN nama file): \\NAMA-PC\WordAddIn → klik Add catalog → centang Show in Menu → OK
  5. Restart Word sepenuhnya.
  6. Buat/buka dokumen → tab Insert → My Add-ins (panah bawah) → tab SHARED FOLDER → pilih PaperFull Word → Add.
  7. Add-in muncul. Klik tombol PaperFull Word di tab Home untuk buka panelnya.
⚠ Catalog Url harus folder UNC (\\PC\Folder), bukan D:\... dan bukan path lengkap ke file .xml. Jika dialog menolak dan minta "https://", versi Word Anda mengunci ke SharePoint — pakai jalur Word di browser di bawah.

🌐 Word di Browser Paling pasti

Berlaku untuk akun Microsoft 365 kantor/sekolah (work/school). Akun personal (gmail/outlook biasa) belum mendukung upload add-in custom.

  1. Buka office.com → login akun Microsoft 365 kantor/sekolah → buka Word.
  2. Buat dokumen baru atau buka yang ada.
  3. Menu Insert (Sisipkan) → Add-ins → Upload My Add-in (Unggah Add-in Saya).
  4. Pilih file manifest.xml yang sudah di-download → Upload.
  5. Panel PaperFull Word muncul di kanan. Selesai.
💡 Tidak ada opsi "Upload My Add-in"? Berarti akun Anda personal. Gunakan akun kantor/sekolah, atau pakai jalur Word Desktop di atas.

🍎 Word untuk Mac

  1. Download manifest.xml.
  2. Salin ke folder: ~/Library/Containers/com.microsoft.Word/Data/Documents/wef
    (buat folder wef bila belum ada)
  3. Restart Word → tab Insert → Add-ins → My Add-ins → Developer Add-ins → pilih PaperFull Word.

✨ Fitur PaperFull Word

  • 📄 Buat Dokumen — ketik topik, AI tulis dokumen lengkap terformat (heading, tabel, list, rumus).
  • 🤖 Agen Edit — AI mengedit dokumen sendiri lewat 35+ alat: cari-ganti, format, style, tabel, gambar, daftar isi, header/footer, catatan kaki, bookmark, komentar, track changes, margin, dan rumus equation asli (LaTeX→OMML).
  • Rumus matematika — tulis $$...$$, jadi equation Word asli yang bisa diedit.
  • Tanya saat ragu — agen berhenti & bertanya bila instruksi ambigu, selalu disertai rekomendasi.
  • Terjemah, ringkas, poles, perbaiki tata bahasa — preset 1-klik pada teks terpilih.

🔧 Troubleshooting

  • Panel kosong / "add-in error" — pastikan ada koneksi internet. Add-in dimuat dari https://wordai.otomasi.app.
  • Add-in tidak muncul setelah Add catalog — tutup Word sepenuhnya (cek Task Manager, pastikan tidak ada proses WINWORD), buka lagi.
  • Dialog Trust Center minta "https://" — versi Word Anda mengunci katalog ke SharePoint. Pakai Word di browser (akun kantor/sekolah).
  • "Upload My Add-in" tidak ada di Word web — akun Microsoft personal tidak didukung; gunakan akun kantor/sekolah atau jalur Desktop.
  • Versi lama tersimpan — tutup-buka panel add-in, atau hapus dari My Add-ins lalu pasang ulang.
