================================================================================
CITATION STYLE GUIDE — IEEE
================================================================================
Use this format for ALL citations in the paper.

── IN-TEXT CITATION FORMAT ──────────────────────────────────────────────────
  Single source     :  "...the system achieved 94.3% accuracy [1]."
  Two sources       :  "...shown in prior work [1], [2]."
  Three or more     :  "...demonstrated in several studies [1], [2], [3]."
  Consecutive range :  "...reported across multiple works [2]–[5]."
  Mixed             :  "...supported by [2], [3], [6]–[8]."
  Author name first :  "Smith et al. [4] reported that..."
  Rules:
    - Numbers in square brackets: [1], [2], [3]
    - Numbered sequentially in order of first appearance in the text
    - Consecutive numbers may be collapsed with em-dash: [3]–[6]
    - Do NOT use author name + year (APA style) — use number only

── REFERENCE LIST FORMAT ────────────────────────────────────────────────────
  Numbered sequentially [1], [2], [3]... in order cited in text.

  Journal Article:
    [N] A. B. Lastname and C. D. Lastname, "Full title of the article,"
        IEEE Trans. Journal Name, vol. XX, no. Y, pp. AAA–BBB, Mon. Year,
        doi: 10.1109/XXXXXXX.Year.XXXXXXX.

  Conference Paper:
    [N] A. B. Lastname, "Full title of the paper," in Proc. IEEE Int. Conf.
        Full Conference Name, City, Country, Year, pp. XX–YY,
        doi: 10.1109/CONFNAME.Year.XXXXXXX.

  Book:
    [N] A. B. Lastname, Title of the Book, Nth ed. City, Country:
        Publisher Name, Year, pp. XX–YY.

  Book Chapter:
    [N] A. B. Lastname, "Chapter title," in Book Title, A. Editor, Ed.
        City, Country: Publisher, Year, pp. XX–YY.

  Online Source:
    [N] A. B. Lastname. (Year). Title of webpage. [Online]. Available:
        https://www.example.com (Accessed: Day Mon. Year).

  Thesis:
    [N] A. B. Lastname, "Thesis title," Ph.D. dissertation / M.S. thesis,
        Dept. Name, Univ. Name, City, Country, Year.

── FORMATTING RULES ─────────────────────────────────────────────────────────
  • Author names: First initials then Last name — "A. B. Lastname"
  • Journal names: official IEEE abbreviation (IEEE Trans. Neural Netw. Learn. Syst.)
  • Paper titles: in "double quotes"
  • Book/journal titles: in Italics (use emphasis in the JSON text if possible)
  • Minimum 20 references; all cited in body text — no orphan references
  • Years: 2010–2025 range preferred; use realistic vol/pp/doi numbers
  • Use real IEEE journal and conference names:
      Journals  : IEEE Trans. Ind. Electron., IEEE Trans. Neural Netw. Learn. Syst.,
                  IEEE Access, IEEE Sensors J., IEEE Trans. Autom. Sci. Eng.,
                  IEEE Robot. Autom. Lett., IEEE Trans. Cybern.
      Conferences: IEEE ICRA, IEEE IROS, IEEE IECON, IEEE ICCAS, IEEE ICC,
                   IEEE Int. Conf. Mechatron. Autom., Proc. IEEE EMBC

── STRUCTURED REFERENCE OUTPUT (CRITICAL) ─────────────────────────────────────
  References MUST be output as structured JSON objects with full metadata,
  NOT as pre-formatted strings. This allows the system to reformat references
  to ANY citation style automatically.

  Each reference in the "references"."items" array MUST be an object:
  {
    "authors": ["Lastname1, Initials1", "Lastname2, Initials2"],
    "year": 2023,
    "title": "Full title of the article/paper/book",
    "type": "journal|conference|book|book_chapter|thesis|website",
    "journal": "Journal Name (for journal articles)",
    "conference": "Conference Name (for conference papers)",
    "volume": "XX",
    "issue": "Y",
    "pages": "AAA-BBB",
    "doi": "10.XXXX/XXXXXXX",
    "publisher": "Publisher Name (for books/theses)",
    "location": "City, Country (for books/theses)",
    "url": "https://... (for websites)",
    "accessed": "DD Mon YYYY (for websites)",
    "editors": ["Editor Name (for book chapters)"],
    "book_title": "Book Title (for book chapters)",
    "institution": "University Name (for theses)"
  }

  Only include fields relevant to the reference type.
  DO NOT output references as formatted strings like "[1] A. Smith, 'Title'..."
  DO NOT include "_CATATAN" or "_ATURAN_REFERENSI" fields in output.
