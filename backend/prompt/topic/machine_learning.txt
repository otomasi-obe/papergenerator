FIELD: Computer Science / Artificial Intelligence / Applied Statistics
DEFAULT CITATION STYLE: IEEE for algorithmic and engineering studies; APA for applied behavioral, education, health, or management ML studies
SUBDISCIPLINE: Classical Machine Learning, Applied Predictive Modeling, Statistical Learning, Explainable ML, AutoML, MLOps

ABSTRACT CHARACTERISTICS:
  150–250 words. Reports prediction/classification task, dataset and sample size, feature engineering, algorithms compared, validation protocol, core metrics, interpretability results, and deployment or domain implications.

INTRODUCTION ELEMENTS:
  - Application context and decision problem requiring prediction, classification, ranking, clustering, anomaly detection, or recommendation.
  - Limitations of manual rules or prior models: low accuracy, poor generalization, class imbalance, drift, lack of interpretability.
  - Research gap: dataset-specific evidence, benchmark gaps, explainability needs, fairness risks, production-readiness limitations.
  - Objectives: develop, compare, explain, or deploy ML models with rigorous validation.
  - Contributions: feature set, model pipeline, benchmark, interpretable analysis, fairness audit, or MLOps workflow.

LITERATURE REVIEW:
  Common section name: "Related Work" / "Background"
  - Supervised learning: linear/logistic regression, decision trees, random forest, SVM, k-NN, Naive Bayes, gradient boosting.
  - Unsupervised learning: k-means, hierarchical clustering, DBSCAN, PCA, anomaly detection, association rules.
  - Model validation: train/test split, k-fold CV, nested CV, bootstrap, temporal validation, external validation.
  - Feature engineering: encoding, scaling, selection, interaction terms, embeddings for tabular/text data.
  - Explainability: permutation importance, PDP/ICE, SHAP, LIME, counterfactual explanations.
  - Responsible ML: fairness metrics, bias mitigation, privacy, robustness, monitoring, reproducibility.

METHODOLOGY:
  Common section name: "Methodology" / "Experimental Setup"
  - Data acquisition: public benchmark, institutional dataset, API logs, sensors, surveys, or transactional records.
  - Preprocessing: missing value imputation, outlier handling, scaling, encoding, leakage prevention, imbalance treatment.
  - Modeling: baseline models, tuned candidates, ensemble methods, hyperparameter optimization.
  - Evaluation: accuracy, precision, recall, F1, ROC-AUC, PR-AUC, MAE, RMSE, MAPE, silhouette, calibration, runtime.
  - Statistical comparison: paired tests, confidence intervals, bootstrap, cross-validated model comparison.
  - Implementation: Python, scikit-learn, XGBoost/LightGBM/CatBoost, Optuna, MLflow, Docker/FastAPI.

TYPICAL RESULTS & DISCUSSION:
  - Tree ensembles often outperform linear baselines on heterogeneous tabular data.
  - Imbalance handling improves recall/PR-AUC but can reduce calibration or precision.
  - SHAP analysis identifies high-impact predictors and supports domain interpretation.
  - Generalization is assessed through external or temporal validation and error analysis.
  - Production discussion covers latency, monitoring, drift, reproducibility, and fairness.

TYPICAL FIGURES:
  - ROC/PR curves, confusion matrix, learning curve, calibration plot, SHAP beeswarm, feature importance, clustering visualization.

TYPICAL TABLES:
  - Dataset summary, preprocessing steps, hyperparameter search space, model comparison, ablation study, fairness metrics, error taxonomy.

CONCLUSION CHARACTERISTICS:
  - Identifies best model with evidence, explains important predictors, states operational usefulness and constraints.
  - Notes limitations: dataset bias, leakage risk, small sample, single-site data, non-causal inference.
  - Suggests future work: external validation, online deployment, drift monitoring, causal analysis, human-in-the-loop review.

LATEX-READY EQUATIONS (doubled backslashes for JSON):
  Accuracy:
    \\mathrm{Accuracy} = \\frac{TP + TN}{TP + TN + FP + FN} \\times 100\\%
  F1-Score:
    F_1 = \\frac{2 \\cdot \\mathrm{Precision} \\cdot \\mathrm{Recall}}{\\mathrm{Precision} + \\mathrm{Recall}}
  Cross-Entropy Loss:
    L = -\\sum_{c=1}^{C} y_c \\log(\\hat{y}_c)
  Softmax:
    \\sigma(z_i) = \\frac{e^{z_i}}{\\sum_{j=1}^{K} e^{z_j}}
  RMSE:
    \\mathrm{RMSE} = \\sqrt{\\frac{1}{n} \\sum_{i=1}^{n} (y_i - \\hat{y}_i)^2}
  ROC-AUC:
    \\mathrm{AUC} = \\int_0^1 \\mathrm{TPR}(\\mathrm{FPR}^{-1}(x))\\,dx
  Gradient Descent:
    \\theta_{t+1} = \\theta_t - \\alpha \\nabla_{\\theta} L(\\theta_t)
