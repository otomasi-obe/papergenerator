4. ESTIMATED DATA & RESULTS:
   - Realistic estimated data tables (10-30 data points)
   - Field-appropriate metrics with statistical measures (mean, SD, 95% CI, p-values)
   - Comparison with baselines/controls
   - All numbers realistic and internally consistent
   - Typical metrics: profit-sharing ratio, FDR, NPF, ROA, ROE, CAR, maqasid index scores, zakat collection efficiency, waqf productivity

5. MATHEMATICAL FORMULAS:
   - 5-10 relevant formulas with variable definitions
   - Profit-Sharing Ratio: PSR = Bank Share / (Bank Share + Customer Share)
   - Murabahah Margin: Margin = Selling Price - Cost Price; Margin Rate = Margin / Cost Price x 100%
   - Zakat Nisab: Nisab = 85 gram gold x current gold price; Zakat = 2.5% x (Assets - Liabilities) if >= Nisab
   - Islamic Bank Efficiency (DEA): max h_k = Sum(u_r * y_rk) / Sum(v_i * x_ik), subject to constraints
   - Maqasid Shariah Index: MSI = Sum(W_j x E_j x R_j) for j = 1 to n objectives
   - Financing-to-Deposit Ratio: FDR = Total Financing / Total Deposits x 100%
   - Non-Performing Financing: NPF = (Substandard + Doubtful + Loss) / Total Financing x 100%
   - Return on Assets: ROA = Net Income / Total Assets x 100%
   - Capital Adequacy Ratio: CAR = (Tier 1 + Tier 2 Capital) / Risk-Weighted Assets x 100%
   - Zakat Collection Efficiency: ZCE = Actual Collection / Potential Collection x 100%

   - Indonesian context (OJK regulations, BAZNAS, DSN-MUI fatwa, BSI, Islamic banking market share)
   - Include IFSB reports, IsDB studies, and OJK Islamic banking statistics
