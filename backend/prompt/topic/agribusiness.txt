   - Value chain analysis (VCA) with governance and upgrading assessment
   - Structural Equation Modeling - Partial Least Squares (SEM-PLS)
   - Data Envelopment Analysis (DEA) for efficiency measurement
   - Cobb-Douglas and translog production function estimation
   - Marketing margin analysis and farmer's share computation
   - SWOT-AHP (Analytic Hierarchy Process) for strategic planning

   - Stochastic Frontier Analysis (SFA) for technical efficiency
   - Panel data regression (fixed/random effects) for policy impact
   - Spatial econometrics for regional agribusiness analysis
   - Business Model Canvas (BMC) for agribusiness startups
   - Life Cycle Assessment (LCA) for sustainability evaluation

4. ESTIMATED DATA & RESULTS:
   - Realistic estimated data tables (10-30 data points)
   - Field-appropriate metrics with statistical measures (mean, SD, 95% CI, p-values)
   - Comparison with baselines/controls
   - All numbers realistic and internally consistent
   - Typical metrics: marketing margin, farmer's share, R/C ratio, B/C ratio, NPV, IRR, technical efficiency scores, elasticity coefficients

5. MATHEMATICAL FORMULAS:
   - 5-10 relevant formulas with variable definitions
   - Marketing Margin: M = Pr - Pf (retail price minus farm-gate price)
   - Farmer's Share: FS = (Pf / Pr) x 100%
   - Profit: pi = TR - TC (Total Revenue minus Total Cost)
   - R/C Ratio = Total Revenue / Total Cost
   - B/C Ratio = Sum[Bt / (1+r)^t] / Sum[Ct / (1+r)^t]
   - NPV = Sum[(Bt - Ct) / (1+r)^t] for t = 0 to n
   - Cobb-Douglas Production Function: Y = A x K^alpha x L^beta
   - Elasticity of Supply: Es = (dQ/Q) / (dP/P)
   - Elasticity of Demand: Ed = (dQd/Qd) / (dP/P)
   - Technical Efficiency (SFA): TE = exp(-u_i), where u_i >= 0

   - Indonesian context (palm oil, coffee, cocoa, rice, shrimp, seaweed, spices, horticulture)
   - Include FAO reports, World Bank agricultural studies, and BPS statistics

  - Sampling: simple random, stratified, multistage cluster, purposive, snowball.
