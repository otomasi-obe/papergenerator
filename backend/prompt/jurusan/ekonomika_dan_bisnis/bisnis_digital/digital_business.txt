3. LATEST METHODOLOGY (2022-2025):
   - Technology Acceptance Model (TAM) and UTAUT/UTAUT2
   - Structural Equation Modeling - Partial Least Squares (SEM-PLS)
   - A/B testing and experimental design for digital interventions
   - Customer journey mapping and touchpoint analysis

   - Machine learning for customer segmentation and prediction

4. ESTIMATED DATA & RESULTS:
   - Realistic estimated data tables (10-30 data points)
   - Field-appropriate metrics with statistical measures (mean, SD, 95% CI, p-values)
   - Comparison with baselines/controls
   - All numbers realistic and internally consistent
   - Typical metrics: CAC, LTV, conversion rate, churn rate, NPS, engagement rate, GMV, MRR/ARR, viral coefficient

5. MATHEMATICAL FORMULAS:
   - 5-10 relevant formulas with variable definitions
   - Customer Acquisition Cost: CAC = Total Marketing Spend / Number of New Customers
   - Lifetime Value: LTV = ARPU x Gross Margin x (1 / Churn Rate)
   - LTV/CAC Ratio: LTV/CAC (healthy if >= 3)
   - Conversion Rate: CR = (Conversions / Total Visitors) x 100%
   - Churn Rate: Churn = (Customers Lost in Period / Customers at Start of Period) x 100%
   - Monthly Recurring Revenue: MRR = Number of Subscribers x ARPU
   - Annual Recurring Revenue: ARR = MRR x 12
   - Unit Economics: Contribution Margin = Revenue per Unit - Variable Cost per Unit
   - Viral Coefficient: K = Number of Invites Sent x Conversion Rate of Invites
   - Gross Merchandise Value: GMV = Number of Transactions x Average Order Value

6. LITERATURE REVIEW WITH EXPLICIT GAPS:
   - 25-30 references thematically organized
   - Each subsection ends with "However, no study has addressed..."
   - Indonesian context (Tokopedia/Shopee, GoPay/OVO/Dana, Indonesian SME digitalization, Kominfo regulations)
   - Include McKinsey/BCG digital economy reports, Google-Temasek e-Conomy SEA reports
