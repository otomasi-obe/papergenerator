---------------------------------

Catat dan gunakan SEMUA informasi berikut dari hasil analisa:

- Page margins (top, bottom, left, right, gutter, header distance, footer distance)

- Footer content (teks, font, size, bold/italic, alignment, fields/page number)

- Semua styles yang digunakan (paragraph styles, character styles)
- Font table (font apa saja yang dipakai)
- Numbering definitions (format numbering section, subsection, list)
- Table border styles
- Body content formatting per paragraf (font, size, bold/italic, alignment, spacing, indent)

HANDLING DATA JSON
================================================================================

ATURAN:
1. Ambil SEMUA data yang ada di _template.json dan generate ke docx
2. Jika suatu field TIDAK ADA di JSON, TETAP tuliskan elemen tersebut dengan:
   - Format yang benar (sesuai template)
   - Isi placeholder yang kontekstual:
     * Title: "Paper Title Goes Here"
     * Author: "Author Name"
     * Affiliation: "Department, University"
     * Email: "author@email.ac.id"
     * Abstract: "Abstract text goes here. This section should contain 150-250 words summarizing the paper."
     * Keywords: "keyword1, keyword2, keyword3"
     * Section content: "Section content goes here."
     * Figure: "[Image placeholder]"
     * Table: minimal 2x2 dengan "Data"
     * Formula: "E = mc^2"
     * References: "[1] Author, Title, Journal, Year."

3. Setelah selesai, LAPORKAN variabel/field apa saja yang perlu ditambahkan ke _template.json

STRUKTUR JSON YANG DIPROSES:
- data["title"] → judul paper
- data["authors"] → list of {name, affiliation, location, email}
- data["abstract"] → teks abstrak
- data["keywords"] → list of string
- data["section1"] → {title, content: [{id, text/...}]}
- data["section1"]["section1a"] → subsection
- data["section2"]["section2a"]["content"] → list items
- Content item types:
  * {"id": "text", "text": "..."}
  * {"id": "gambar", "ImageNumber": "1", "Title": "...", "Path": "..."}
  * {"id": "rumus", "FormulaNumber": "1", "latex": "..."}
  * {"id": "tabel", "TableNumber": "I", "Title": "...", "Headers": [...], "Rows": [[...]]}
- data["references"] → {title, content: [list of string]}

    add_authors(doc, data)
