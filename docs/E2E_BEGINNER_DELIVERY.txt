🚀 HOW TO RUN
═══════════════════════════════════════════════════════════════════════

1. ENSURE SERVICES ARE RUNNING
   $ pm2 list
   # or
   $ ./server.sh

2. RUN THE TEST (Choose one)
   
   # Quick run
   $ cd frontend && npm run test:e2e -- beginner-first-time.spec.js

   $ ./frontend/e2e/run-beginner-test.sh

   # Debug mode
   $ ./frontend/e2e/run-beginner-test.sh --debug

3. VIEW RESULTS
   $ npx playwright show-report
